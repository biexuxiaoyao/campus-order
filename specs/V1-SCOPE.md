# V1-SCOPE — V1.0 范围清单

> V1.0 是完整商用目标，不等于所有功能必须同一批次进入试点。实际排期必须先参考 `PRODUCT-STRATEGY-SPEC.md`，按 Demo 可演示版、试点可上线版、正式可销售版、源码交付版分层验收。

## 交付分层原则

| 层级 | 目标 | 范围判断 |
|---|---|---|
| Demo 可演示版 | 支持销售演示和内部评审 | 允许支付/打印 mock，但必须清楚标注演示模式 |
| 试点可上线版 | 支持 1-3 家真实商家试营业 | 必须打穿个人点餐、团餐拼单、商家高峰处理三条闭环 |
| 正式可销售版 | 支持标准 SaaS 售卖 | 补齐平台后台、营销闭环、消息、审计、测试覆盖 |
| 源码交付版 | 支持源码买断 | 补齐模块裁剪、交付包、部署文档、售后边界 |

## 试点 P0 闭环

试点上线不得被积分商城、商品券、公司储值卡、复杂折扣、自动源码交付队列阻塞。试点 P0 只看以下三条闭环是否稳定：

1. **个人点餐闭环**：菜单浏览 → SKU 选择 → 购物车 → 提交订单 → 微信支付 → 商家接单 → 厨房制作 → 用户取餐 → 完成。
2. **团餐拼单闭环**：发起团单 → 分享 → 多人加入 → 截单 → 商家看到团单汇总 → 厨房按团单备餐 → 完成。
3. **商家高峰处理闭环**：新订单提醒 → 订单列表 → 厨房大屏 → 打印/补打 → 批量出餐 → 今日对账。

## ✅ IN — V1.0 必须交付

### 小程序用户端
- 微信登录/静默续期
- 菜品浏览(分类+搜索+SKU选择+多时段菜单)
- 购物车(服务端存储+24h保留+异常处理)
- 个人点餐(下单→微信支付/余额支付→取餐号)
- 订单管理(时间轴+再来一单+催单+退款申请)
- 拼单模式(全楼可见, A/B两种成立条件)
- 代表下单(为团队选餐+统一支付)
- 个人储值卡购买和使用
- 积分(签到+消费积分+抵现+兑换)
- 优惠券(领取+自动匹配+使用)
- "我的"页面(余额/积分/券/订单/设置/隐私)
- 品牌配置加载+本地兜底

### 商家管理后台(Web)
- 用户名+密码登录(含锁定/忘记密码)
- 数据看板(今日营收/订单/Top10/日对账)
- 菜品管理(CRUD+规格SKU+估清+定时上下架+批量导入导出)
- 订单管理(确认/取消/退款审批+批量确认+订单标签)
- 团单管理(查看详情+参与者订单)
- 厨房模式(全屏+大字体+5s自动刷新+一键出餐)
- 营业设置(时间/暂停接单/打印机)
- 角色管理(老板/店长/收银/厨师)
- 操作日志(6个月保留)
- 品牌配置编辑
- 折扣规则管理
- 积分规则+兑换商品管理
- 优惠券模板管理
- 门店小程序码下载
- CSV数据导出

### 平台管理后台(Web)
- 商家入驻审核(四证: 营业执照+食品经营许可证+身份证+门店照)
- 模块分配
- License签发/吊销
- 版本管理
- 大盘数据
- 数据修正(需密码+理由+审计)
- 商家到期/退出管理

### 后端
- 多租户中间件(appId→tenant_id)
- JWT认证(C端24h refresh, B端12h)
- 乐观锁并发控制
- 定时任务(支付超时/回调补偿/积分过期/菜品上下架/打烊完成)
- 菜单缓存(60s, 修改主动清除)
- 微信支付对接(APIv3, 统一下单/退款/回调验签/幂等)
- 订阅消息推送(8种场景)
- 云打印机对接(易联云/飞鹅/商米, 自动+手动+容错)
- 文件上传(OSS/CDN SaaS, 本地存储源码交付)
- API分页+限流+CSRF+CORS
- 操作日志+审计
