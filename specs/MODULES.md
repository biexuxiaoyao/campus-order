## 软依赖行为

| 软依赖缺失时 | 降级行为 |
|---|---|
| 无 `prepaid` | 支付方式不展示"公司储值卡"和"个人余额" |
| 无 `discount` | 不展示折扣标签, 结算不计算折扣 |
| 无 `points` | "我的"页面不展示积分入口, 折扣动作"赠送积分"无效 |
| 无 `coupon` | 结算页不展示优惠券区域, 积分兑换不展示"兑换券"选项 |
| 无 `printer` | 管理后台不展示打印机设置和"补打"按钮 |
| 无 `push-notify` | 不发送订阅消息, 管理后台无语音播报(订单列表静默刷新) |

## 模块加载机制

1. P端为商家开通模块 → `tenant_modules` 表记录
2. 商家登录管理后台 → 后端返回 `tenant.modules[]` → 前端 ModuleLoader 只注册已购模块的路由/菜单
3. 小程序启动 → 品牌配置接口返回 `enabledModules[]` → 首页功能入口动态显隐
4. 源码交付 → packager 根据白名单物理删除未购模块目录
