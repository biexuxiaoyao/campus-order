## 多租户架构

- 每个商家拥有独立的微信小程序 AppID
- 后端共享一个 NestJS 实例
- 请求通过 `x-app-id` Header 识别租户 → 中间件注入 `tenant_id` 到请求上下文
- 所有数据库查询自动附加 `WHERE tenant_id = ?`
- C端不存在"切换商家"——用户打开哪个小程序就看到哪个商家

## 调度任务

| 任务 | 频率 | 说明 |
|---|---|---|
| 支付超时取消 | 每分钟 | 取消超时未支付订单，释放库存 |
| 支付回调补偿查询 | 每分钟 | 查过去5分钟内待支付订单 |
| 积分过期清零 | 每日凌晨 | 扫描过期积分 |
| 菜品定时上下架 | 每分钟 | 检查 scheduled_publish_at |
| 营业结束自动完成 | 每日关店时 | 待取餐→已完成 |
